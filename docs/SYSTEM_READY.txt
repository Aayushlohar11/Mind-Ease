⚙️ QUICK SETUP

Step 1: Install MongoDB
  macOS:    brew install mongodb-community && brew services start mongodb-community
  Ubuntu:   sudo apt install mongodb && sudo systemctl start mongodb
  Windows:  Download from mongodb.com/try/download/community

Step 2: Configure Environment
  Edit .env.local and add:
  
  MONGODB_URI=mongodb://localhost:27017/mindease
  AUTH_TOKEN_SECRET=your-super-secret-jwt-key
  RESEND_API_KEY=your-resend-api-key

Step 3: Start Your App
  npm run dev
